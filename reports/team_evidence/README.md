# Team evidence handoff

Store only evidence the team is authorized to submit. Do not add private chat exports, access tokens, student documents, or unrelated personal information.

Recommended final contents:

- `roster_approval.pdf` or a redacted screenshot showing lecturer approval for four members;
- `registration_confirmation.pdf` showing the registered group roster;
- `progress_reports/` containing the reports actually submitted to the LMS;
- `meetings/` containing dated minutes and, where appropriate, meeting screenshots;
- `contribution_signoff.pdf` confirming each member's tasks and agreed contribution percentage.

Use ISO dates in filenames, for example `meetings/2026-10-15-minutes.md`. Every meeting note should record attendees, decisions, assigned actions, and links to commits or artifacts. The evidence in this directory must agree with the contribution table in `report_vi.tex`.
